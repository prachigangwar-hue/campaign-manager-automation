# Repository working rules

- This is a sanitized archive of campaign-related source, not an authorization to execute production jobs.
- Never delete or modify server files without explicit user permission.
- Follow objective -> SQL review -> approved validation -> script review -> approved deployment -> approved schedule and registration.
- Keep customer data, credentials, notebook outputs and generated campaign files out of Git.
- Preserve server-relative structure and document any changes made to copied code.
- Do not enable automatic deployment, campaign execution, communications or scheduled jobs without permission.
- Verify service identities and live Sheet headers rather than relying on historical IDs.
